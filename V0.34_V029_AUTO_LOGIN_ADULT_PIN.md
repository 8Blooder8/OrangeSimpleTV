# v0.34 — v0.29 base + auto-login + adult PIN

## Base

v0.34 is forked directly from `v0.29-channel-activation-diagnostics`. The source-level goal is to preserve the known-working v0.29 discovery, switch, diagnostics and playback paths.

## Added login lifecycle

- v0.29 login form and `loginStep()` automation remain the authentication mechanism.
- A valid pre-existing Orange session is still probed exactly as in v0.29.
- When no valid session exists and enrollment has not happened yet, the normal v0.29 login UI is shown once.
- After the first authenticated session, an app-local enrollment flag is stored.
- After enrollment, missing or expired Orange sessions are renewed automatically using the private appliance credentials.
- Login identifier case is not transformed.

## Added adult-PIN flow

Only while waiting for a target player after a real Play activation, the app checks for Orange's own adult-control modal. It can fill a 4-digit input, four one-character inputs, or the Orange numeric keypad, submit the code, then retap the same verified channel once if Orange closes the modal without creating the player immediately.

## Explicitly unchanged from v0.29

- channel discovery and metadata enrichment,
- EPG and local-logo logic,
- exact-X old player close,
- close-before-tune,
- channel identity validation,
- warm-switch timing and one reload fallback,
- activation diagnostics and network/resource evidence,
- full `pageState()` tune loop,
- official Orange player, DRM, Widevine, MSE/EME and media source handling.

No secret values are stored in this repository documentation.
