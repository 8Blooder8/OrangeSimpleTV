# v0.29 — channel activation diagnostics + bounded recovery

## Powód zmiany

Realny raport DIW377 dla `Warner TV -> Kino Polska HD` w v0.28 pokazał:

- stary player został poprawnie zamknięty,
- prawidłowy kafelek `Kino Polska HD` został aktywowany,
- po pierwszym Play Orange nie utworzył `player-container`,
- wykonano jeden reload `/channels`,
- po reloadzie aplikacja ponawiała Play jeszcze kilka razy co ok. 8 s,
- mimo to nigdy nie pojawił się `TARGET_PLAYER_CREATED` i sesja kończyła się `TUNE_TIMEOUT`.

To jest etap **przed** MSE/EME/Widevine/video, więc v0.29 nie zmienia DRM ani render gate.

## Nowy limit aktywacji

Po realnym `NATIVE_TAP_PLAY`:

1. jedna normalna próba Play,
2. jeśli player nie powstaje — jeden świeży reload oficjalnego `/channels`,
3. jedna finalna próba Play,
4. jeśli player nadal nie istnieje — terminalny `CHANNEL_PLAYER_NOT_CREATED`.

Po wejściu w ten fallback nie uruchamiamy już starej drabiny UA/cache/WebView-recreate dla pustego DOM po reloadzie. Strona ma do 7 s na wyrenderowanie listy; potem kończy się `CHANNEL_LIST_UNAVAILABLE_AFTER_RELOAD`.

## Diagnostyka aktywacji

Każdy `ostv-switch-session-<id>.json` zawiera dodatkowo `activationDiagnostics`, `activationNetwork` i `sanitizedWebDiagnostics`.

`activationDiagnostics` zapisuje m.in. snapshoty `before-hover`, `post-hover-play-mounted`, `post-tap-250ms`, `post-tap-1200ms`, `before-reload-fallback` i `final-no-player`. Zawierają faktycznie znaleziony kanał, DOM kafelka, prawdziwy Play, React handler, widoczne alerty/dialogi/toasty, stan playera i istotne Resource Timing wraz z `responseStatus`, gdy Chromium go udostępnia.

`activationNetwork` zapisuje metodę HTTP, bezpieczny URL bez query string, czas względem switchu, błędy transportu oraz HTTP >= 400. Nie zapisuje nagłówków, cookies ani tokenów.

## Bez ingerencji w Orange media

v0.29 nie podmienia `video.src`, nie ustawia `MediaKeys`, nie przechwytuje ani nie zastępuje `fetch`/XHR i nie tworzy własnego MSE/EME pipeline.

Najważniejszy plik po kolejnym teście niedziałającego kanału: `ostv-switch-session-<id>.json`.
