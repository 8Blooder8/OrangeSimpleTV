# v0.32 — one manual login, then automatic only

Contract:

- after install or app-data reset the normal local login form is shown once;
- the private appliance credentials may be prefilled, but the first submit requires explicit `ZALOGUJ`;
- successful first login stores an app-private enrollment marker;
- afterwards credential fields stay hidden;
- valid Orange cookies are reused;
- missing, expired or rejected sessions are recovered only by automatic login;
- discovery authentication recovery follows the same automatic-only rule after enrollment;
- clearing app data or uninstalling intentionally resets enrollment.

Credential and PIN values are not stored in this repository documentation or diagnostics.
