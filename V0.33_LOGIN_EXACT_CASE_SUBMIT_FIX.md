# v0.33 — exact-case login + two-phase submit

Real source review found a regression introduced in v0.31/v0.32: the configured TV login was forcibly canonicalized by changing a leading lowercase `m` to uppercase `M`. v0.33 removes that transformation and passes the configured identifier exactly as supplied.

The login bridge also changes submission ordering. Orange/React controlled inputs are filled first and the bridge returns without submitting. A later bridge turn verifies that both values are still present and only then triggers the enabled submit control. This prevents a submit racing React state propagation.

The v0.32 lifecycle remains: one explicit enrollment after install/app-data reset, then automatic session reuse/recovery only. No credential or PIN values are stored in repository documentation.
