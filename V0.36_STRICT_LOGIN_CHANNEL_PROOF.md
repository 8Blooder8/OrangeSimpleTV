# v0.36 — strict login proof before channel discovery

Base runtime remains v0.29. v0.36 changes only the login/enrollment layer added on top of v0.29 and keeps the adult-PIN helper.

Physical v0.35 diagnostics from DIW377 showed four consecutive guide timeouts with exactly the built-in 8 fallback channels, zero Orange programme metadata and zero discovered EPG entries. The v0.35 login state could treat the generic Orange home/navigation/app shell as authenticated before real channel cards existed.

Changes:

- authentication is accepted only after at least 3 real `[data-testid="Channel-ChannelWrapper"]` cards exist;
- generic Orange home/navigation/app shell is reported as `SHELL`, never `AUTH`;
- after login lands on Orange home, the app navigates once to `/channels` and waits for real cards before hiding the login layer and starting v0.29 discovery;
- existing-session probing likewise requires real channel cards and no longer uses generic navigation text as proof;
- startup no longer focuses an EditText, avoiding unnecessary DIW377 TV IME activation;
- v0.29 discovery/player/switch/EPG/DRM code remains unchanged;
- automatic adult PIN handling remains unchanged.
