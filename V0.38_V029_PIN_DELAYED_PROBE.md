# v0.38 — v0.29 + delayed adult PIN probe

Physical DIW377 report from v0.37 showed a verified `Kino Polska HD` Play tap followed by an Orange adult-code modal. The modal was visible in the delayed activation diagnostic about 1.2–1.4 seconds after the trusted Play tap, but the regular tune polling path did not execute the PIN action before the v0.29 reload fallback.

v0.38 keeps the v0.29 login/discovery/player/switch/DRM path unchanged and adds several bounded delayed calls to the existing `adultGateStep` immediately after a verified native Play tap. The calls are no-op when the Orange adult gate is absent.

The configured PIN value is private and is not present in this public documentation branch.
