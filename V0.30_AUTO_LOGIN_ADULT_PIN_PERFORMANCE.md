# OrangeSimpleTV v0.30 — auto-login, adult PIN, fast tuning path

## Cel

v0.30 jest prywatnym buildem „appliance mode” dla jednego konta Orange TV Go. Po uruchomieniu aplikacja ma sama:

1. wykorzystać istniejącą sesję Orange, jeśli cookie nadal jest ważne,
2. w przeciwnym razie automatycznie otworzyć oficjalny formularz Orange i zalogować konto skonfigurowane w buildzie,
3. wykryć oficjalny modal kodu dorosłych i wprowadzić skonfigurowany 4-cyfrowy PIN,
4. po odblokowaniu programu kontynuować uruchamianie tego samego kanału bez ręcznej obsługi,
5. zachować oficjalny player Orange, MSE/EME/Widevine i źródło streamu bez modyfikacji.

## Root cause z v0.29

Raport DIW377 dla Kino Polska HD pokazał, że target tile i prawdziwy `IconPlayerPlay` były poprawne, request `/gpapi2/live/channel/.../session` odpowiadał HTTP 200, ale Orange pokazywał modal wymagający nadania/użycia kodu dorosłych. Player nie miał prawa powstać dopóki gate nie został rozwiązany.

v0.30 dodaje `adultGateState()` i `adultGateStep()`:

- rozpoznawanie modali/dialogów kodu dorosłych i kontroli rodzicielskiej,
- obsługa jednego pola PIN,
- obsługa wielu jednoznakowych pól PIN,
- obsługa ekranowej klawiatury 0–9,
- obsługa przycisków potwierdzenia/odblokowania,
- bounded retry i jawne błędy `ADULT_PIN_*`,
- po prawidłowym PIN aplikacja daje Orange krótki czas na utworzenie playera; jeśli wymagany jest ponowny Play, target jest klikany dokładnie jeden raz.

PIN nie jest dopisywany do logów diagnostycznych.

## Auto-login

- ręczne pola loginu są ukryte,
- przy braku cookie login startuje automatycznie,
- przy wygasłej sesji po probe aplikacja automatycznie ponawia oficjalny login,
- przy błędzie pozostaje `PONÓW LOGOWANIE`, który wykonuje ten sam automatyczny flow,
- bridge nadal używa React-friendly `input`/`change` i czeka na rzeczywiście aktywny submit.

Wartości konta/PIN są skonfigurowane tylko w prywatnym source ZIP/APK i nie są publikowane w repozytorium.

## Optymalizacje hot path

- `pageStateLite()` zastępuje pełny `pageState()` w pętli tune,
- `activateChannel()` nie serializuje już ciężkiego DOM/ResourceTiming/full-page diagnostics przed każdym prawidłowym tapem,
- usunięto snapshoty 250 ms / 1200 ms po każdym udanym tapie,
- `shouldInterceptRequest` nie buduje JSON eventu dla każdego requestu; zostają błędy HTTP/network i ResourceTiming na realnej awarii,
- `playerAction()` nie przenosi pełnej `emeMatrix` w każdym `VIDEO_WAIT`; pełna macierz pozostaje w diagnostyce terminalnej,
- nie zmieniono close-before-tune, identity check, rendered-frame gate, live-edge ani logiki DRM.

## Bezpieczeństwo

Automatyczne logowanie bez interakcji wymaga, aby sekret był lokalnie dostępny aplikacji. Ten build należy traktować jako prywatny i nie udostępniać APK ani source ZIP osobom trzecim.
