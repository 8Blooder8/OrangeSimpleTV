# v0.24 Windows asset packaging fix

Fizyczny build na Windows Build-Tools 36 ujawnił, że zagnieżdżony katalog `assets/channel_logos` nie był dostępny w finalnym APK pod ścieżką oczekiwaną przez `AssetManager`.

Naprawa:

- `AAPT2 link` nie pakuje już `assets/` przez `-A`;
- po utworzeniu resource APK cały katalog `app/src/main/assets` jest dokładany przez JDK `jar` jako `assets/...`;
- jeszcze przed `zipalign` build sprawdza `assets/orange_bridge.js`, `assets/channel_logos/catalog.json` i dokładnie 155 plików `logo_###.png`;
- identyczna kontrola jest wykonywana po podpisaniu finalnego APK;
- zmiany w samych assets nie invalidują już kosztownego AAPT2 link cache.

Wersja aplikacji pozostaje `0.24.0`, ponieważ jest to naprawa procesu pakowania źródła v0.24, które wcześniej nie mogło przejść własnej walidacji na Windows.
