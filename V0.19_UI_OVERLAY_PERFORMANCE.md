# v0.19 — TV guide overlay + performance

## UI

- Pełny guide przed odtwarzaniem: lista po lewej, duży placeholder/podgląd po prawej i karta aktualnego programu pod nim.
- Brak dolnej legendy / paska ustawień.
- Loga mają transparentne tło — aplikacja nie dokłada ciemnych prostokątów.
- Focus to ciemna karta z cienką pomarańczową ramką.
- OK podczas oglądania pokazuje własną kartę kanału/programu.
- Po BACK z działającego kanału lista pojawia się tylko jako lewy overlay. WebView/custom video pozostaje full-screen i nie jest resizeowany, pauzowany ani przeładowywany.
- Drugie BACK zamyka overlay i wraca do pełnego obrazu.

## Emulator bez Widevine

Emulator używa natywnego placeholdera video. Wybranie kanału nie uruchamia DRM, dzięki czemu można testować full-screen placeholder, CH+/CH-, boczny guide po BACK i kartę programu po OK. Na fizycznym urządzeniu ścieżka Orange/Widevine pozostaje bez zmian.

## Szybkość

- kanały + nazwy programów są cacheowane i pokazywane natychmiast przy kolejnym wejściu,
- świeże dane Orange aktualizują cache w tle,
- loga mają cache RAM + dyskowy,
- 6 workerów pobiera loga równolegle,
- aktualny kanał i pierwsze 24 pozycje mają pierwszeństwo,
- zachowany jest warm switch bez reloadu `/channels`,
- Play reveal poll skrócono do 45 ms,
- fallback rozpoznawania podmienionego playera skrócono z 650 ms do 350 ms,
- polling logowania/discovery jest szybszy, ale nadal bounded.

Observe-only media pozostaje bez zmian: brak własnego `src`, MediaKeys i ingerencji w DRM.
