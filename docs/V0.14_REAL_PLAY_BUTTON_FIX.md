# v0.14 — real Orange Play-button activation

The user-provided diagnostic trace resolved the channel activation bug.

## Proven flow

1. `Channel-ChannelWrapper` contains a `TileWrapper` sized 196×140 in the captured viewport.
2. `TileWrapper` owns React `onMouseEnter` / `onMouseLeave`; it does **not** own the tuning `onClick`.
3. Hover changes the tile state and React mounts a centered channel control asynchronously.
4. The tuning control is a real 40×40 `<button>` containing `IconPlayerPlay`, centered at the same coordinates as the tile center.
5. The successful trusted click lands on the SVG/path inside that button.
6. Orange then mounts `global-loader`; later `player-container mode="expanded"` appears, followed by playing video.
