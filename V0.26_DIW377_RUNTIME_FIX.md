# v0.26 — DIW377 runtime fix

## Playback — dokładna przyczyna timeoutu

Raport v0.25 z fizycznego DIW377 pokazał jednocześnie `channelActivated=true`, granty protected media, `readyState=4`, `paused=false`, `1024x576`, `renderSignal=rvfc` i setki stanów `PLAYING`, a mimo to kończył `TUNE_TIMEOUT`.

Pomiędzy kolejnymi stanami `PLAYING` konsola zgłaszała `Uncaught SyntaxError: missing ) after argument list`.

`evalBridge()` opakowuje argument jako `JSON.stringify(<expression>)`. v0.25 przekazywała dwa łańcuchy `fn1(); fn2(); fn3()`, które nie są pojedynczym expression po takim opakowaniu. Jeden błąd psuł initial page-state probe i wymuszał reload `/channels`; drugi psuł `finishCleanPlayerFast()`, więc realnie działający player nigdy nie wykonywał `finishTune()`.

v0.26 używa poprawnych pojedynczych expressions przez operator przecinka: `(fn1(), fn2(), fn3())`.

## EPG — utrata metadata

Raport guide v0.25 miał `programs=154`, `schedules=149`, `channelsTotal=164`, ale natywne podsumowanie miało `programNamesResolved=0` i `schedulesResolved=0`.

Przyczyna: `discoveryBest` preferował bezwarunkowo większy snapshot. Pełne 164 cards bez zamontowanych programów wygrywały z chwilowo mniejszym, ale bogatszym snapshotem. v0.26 utrzymuje union po channel identity i monotonicznie scala niepuste program/schedule/description.

## EPG performance

`harvestJsonEpg()` używał `queue.shift()` oraz `seen.indexOf(object)` w dużych grafach React/JSON. To dawało zachowanie kwadratowe i na DIW377 nominalne 6 s discovery potrafiło wrócić dopiero po ~32 s.

v0.26 używa kursora kolejki, `WeakSet` i krótkiego budżetu czasu dla globalnego React fallbacku. Hover `Channel-ProgramTime` pozostaje źródłem deterministycznym.

## Hover sweep

Każdy krok ponownie pobiera aktualne host nodes, hoveruje jeden kafelek, czeka ~32 ms, przechwytuje `Channel-ProgramTime`, wykonuje mouse leave i zawsze przechodzi dalej przez `finally`. React remount jednego kafelka nie może zatrzymać całego przebiegu.

## Logo i numery

Mechanizm v0.25 zostaje: logo jest mapowane tylko po identity/nazwie, bez fallbacku po numerze. Nieznany kanał pozostaje bez logo zamiast dziedziczyć cudzy asset. Numeracja ma kontrolę kolizji.
